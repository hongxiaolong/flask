# 宠物电商网站

这是一个功能完整的宠物用品在线商城，使用 Flask 框架开发。网站提供宠物食品、用品、玩具等商品的展示和购买功能。

## ✨ 特性

- 商品分类浏览
- 商品详情展示
- 购物车功能
- 响应式设计
- 商品库存管理

## 💁‍♀️ 如何使用

- 安装 Python 依赖: `pip install -r requirements.txt`
- 启动开发服务器: `python3 main.py`
- 访问网站: `http://localhost:5000`

## 🛒 功能说明

- 首页展示所有商品
- 可按分类浏览商品
- 商品详情页显示完整信息
- 支持添加商品到购物车
- 响应式设计，支持移动端访问
